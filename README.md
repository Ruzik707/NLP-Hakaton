# Tatar Text Detoxification Hackathon

Командный NLP-проект для задачи детоксикации текста на татарском языке.

Проект был выполнен в рамках хакатона «ИИ-ЗАМАН Хак». Основная задача хакатона заключалась в создании системы искусственного интеллекта для преобразования токсичных татарских фраз в нейтральные формулировки с сохранением исходного смысла.

## Моя роль

В команде я отвечал за data-centric часть проекта:

* сбор и подготовку пар “токсичный текст → нейтральная формулировка”;
* очистку датасета и удаление некорректных/повторяющихся примеров;
* проверку качества татарского языка;
* проверку сохранения исходного смысла после нейтрализации;
* лингвистическую валидацию разметки как носитель татарского языка.

Модельный блок был реализован командой как экспериментальный прототип. Репозиторий содержит notebook с LoRA fine-tuning модели `Tweeties/tweety-7b-tatar-v24a`, однако проект не позиционируется как production-ready модель.

## Датасет

Датасет содержит пары текстов в формате:

```json
{"input": "токсичный текст", "output": "нейтральная формулировка"}
```

Текущий объем датасета: **7к+ пар**.

Данные были подготовлены в условиях ограниченного времени хакатона. Токсичные примеры генерировались с помощью нейросетевых инструментов, после чего проходили ручную очистку и лингвистическую проверку.

## Модельный эксперимент

В репозитории представлен notebook с экспериментальным LoRA fine-tuning модели `Tweeties/tweety-7b-tatar-v24a`.

Использованный стек:

* PyTorch
* Hugging Face Transformers
* PEFT / LoRA
* TRL / SFTTrainer
* Unsloth
* Google Colab GPU

Train loss использовался только как технический индикатор того, что обучение запускалось и сходилось. Он не является полноценной оценкой качества детоксикации.

## Ограничения

* Проект был выполнен в формате хакатона и не является production-ready решением.
* Датасет создавался в условиях ограниченного времени.
* Часть текстов была сгенерирована нейросетевыми инструментами и затем вручную проверялась.
* Для полноценной оценки качества нужны отдельные метрики: сохранение смысла, нетоксичность, fluency/адекватность и human evaluation.
* Модельный эксперимент не стоит интерпретировать как финальную качественную систему.

## Что можно улучшить

* Добавить валидационную и тестовую выборки с фиксированным split.
* Провести human evaluation на татарском языке.
* Сравнить несколько моделей и prompting/fine-tuning подходов.
* Добавить метрики semantic similarity, toxicity score и fluency.
* Подготовить inference script для проверки модели на новых примерах.
