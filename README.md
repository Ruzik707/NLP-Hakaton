**Участие в хакатоне по преобразованию токсичных текстов в корректные формулировки с сохранением смысла.**

## 📌 Описание задачи

**Цель:** Разработать модель, которая переформулирует токсичные или агрессивные высказывания в вежливые и уважительные, максимально сохраняя исходный смысл.

**Пример:**
Вход: Чәй эчкәндә дә дуңгыз кебек эчәсең, чапылдатасың, тәрбиясез, өйдә өйрәтмәделәрме сине?
Выход: Чәй эчкәндә тавыш чыгарма, тәрбияле бул, саклык белән эч.

## 🚀 Решение

### Подход
- Использование предобученных языковых моделей для парафразирования
- Fine-tuning на датасете токсичных/нетоксичных пар текстов
- Оценка качества через метрики BLEU и сохранение семантики

### Технологический стек
- **Фреймворк:** PyTorch / Transformers
- **Модель:** MT0/MT5/ruT5
- **Библиотеки:** Hugging Face Transformers, Datasets, Evaluate
- **Инфраструктура:** Google Colab, Hugging Face Spaces

### Ключевые особенности
1. **Подготовка данных:** Очистка и аугментация датасета
2. **Fine-tuning:** Адаптация модели под задачу детоксификации
3. **Инференс:** Реализация пайплайна для преобразования текстов
4. **Деплой:** Модель загружена на Hugging Face для демонстрации
