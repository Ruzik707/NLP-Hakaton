# Tatar Text Detoxification — данные для малоресурсного NLP

Командный проект хакатона «ИИ-ЗАМАН Хак»: преобразование токсичного татарского
текста в нейтральный с сохранением смысла.

**Мой основной вклад:** сбор и очистка пар, лингвистическая проверка татарского
языка и сохранения смысла как носителем; участие в командных экспериментах с LoRA.
Обучение модели — командный эксперимент.

## Подготовленные данные

[total.jsonl](total.jsonl) содержит **7 511 пар**: непустые строковые `input` и
`output`, точных повторов пар нет. Проверка структуры не заменяет экспертную
оценку языка. Примеры создавались генеративными моделями и проходили ручную очистку
и лингвистическую проверку в условиях хакатона. Корпус содержит токсичный текст.

```json
{"input": "исходный текст", "output": "нейтральная формулировка"}
```

## Быстрый просмотр без GPU

```bash
git clone https://github.com/Ruzik707/NLP-Hakaton.git
cd NLP-Hakaton
python validate_dataset.py
```

Скрипт использует стандартную библиотеку Python и выводит статистику без печати
токсичных примеров. Некорректные записи вызывают ошибку.

## Модельный эксперимент

[train_tatar_detox.ipynb](train_tatar_detox.ipynb): `Tweeties/tweety-7b-tatar-v24a`,
4-bit загрузка через Unsloth, LoRA rank 16, chat template Mistral, `SFTTrainer`.
Разделение 90/10 с фиксированным seed 3407, одна эпоха; сохраняются адаптер и merged-модель.

Ноутбук рассчитан на GPU/Colab. В нём сохранены команды установки использованного
окружения; `requirements.txt` перечисляет библиотеки, но не фиксирует всю комбинацию
версий. Загрузите `total.jsonl` в рабочую директорию и выполняйте ячейки последовательно.
Публикация в Hugging Face отключена по умолчанию и включается через `publish_model`.

## Качество и ограничения

Train loss отражает ход обучения, а не качество детоксикации. Независимый итоговый
test, метрики токсичности, сохранения смысла и fluency, human evaluation не представлены.
Синтетический корпус не покрывает всё разнообразие татарской речи. Для сравнения
моделей нужны отдельный test и экспертная проверка, исключённые из подбора модели.
